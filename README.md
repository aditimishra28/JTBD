# JTBD - Jobs to be Done

A comprehensive repository for Jobs to be Done (JTBD) analysis and implementation.

## Overview

This repository contains tools, frameworks, and resources for conducting Jobs to be Done analysis. JTBD is a methodology for understanding customer needs and motivations by focusing on the "jobs" customers are trying to accomplish, rather than their demographics or stated preferences.

## 📁 Contents

- **jtbd-analyst.skill** - Core skill definitions and analytical frameworks for JTBD practitioners

## 🎯 What is Jobs to be Done?

Jobs to be Done theory proposes that customers don't simply buy products or services; they hire them to do a job. Understanding these jobs helps create better products and marketing strategies by focusing on customer needs and desired outcomes.

### Key Concepts

- **Functional Jobs** - The practical tasks customers are trying to accomplish
- **Emotional Jobs** - How customers want to feel
- **Social Jobs** - How customers want to be perceived by others
- **Progress** - The change or improvement customers seek
