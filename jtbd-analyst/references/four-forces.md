# The Four Forces of Progress

> Distilled from Kalbach, *The Jobs to Be Done Playbook*, Ch. 3, drawing on Bob Moesta's Switch technique. See `sources.md`.

The Four Forces explain **why people do or don't switch** from their current way of getting a job done to a new one. Use this lens only when the data contains switching behavior — frustration with the status quo, attraction to an alternative, hesitation, or inertia.

## The four forces

Two forces drive change; two resist it.

| Force | Direction | What it is | Listen for |
|---|---|---|---|
| **Push** | → toward change | Frustration with the current situation | "I was sick of…", "it kept failing…", a triggering event |
| **Pull** | → toward change | Attraction of a new solution | "I saw it could…", "I imagined finally being able to…" |
| **Anxiety** | ← resisting change | Worry about the new solution | "I wasn't sure it would…", "what if it doesn't…" |
| **Habit** | ← resisting change | Attachment to the current way | "I'm used to…", "it's just easier to keep…" |

Progress happens when **Push + Pull > Anxiety + Habit**. To grow demand you can amplify push/pull, but the bigger lever is usually **reducing anxiety and overcoming habit** — these are what stall otherwise-motivated switchers.

## The Switch timeline

Switch interviews reconstruct the story of a single purchase/adoption as a timeline of energy building toward a decision:

1. **First thought** — the moment the performer first realized the old way wasn't working.
2. **Passive looking** — loosely aware of alternatives, not yet committed.
3. **Active looking** — actively evaluating options (Push and Pull intensify).
4. **Deciding** — committing to a new solution (Anxiety and Habit must be overcome).
5. **Onboarding / first use** — living with the new solution; new habits form.

Map each force to moments on this timeline to see what tipped the decision — and what nearly stopped it.

## Using it in an analysis

- Populate the Four Forces table only with evidence; mark inferences.
- A strong **Push + weak Pull** signals an unmet need with no adequate solution yet — an opportunity.
- High **Anxiety / Habit** that kills otherwise-motivated switches points to onboarding, guarantees, migration help, or proof points as the intervention.
