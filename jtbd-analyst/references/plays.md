# The JTBD Play Catalog

> Distilled from Kalbach, *The Jobs to Be Done Playbook*, Ch. 3–7. The book organizes JTBD techniques as "plays" across five value-creation stages. Use this catalog to pick the right **Suggested Next Step** at the end of an analysis. See `sources.md`.

The value-creation cycle moves: **Discover → Define → Design → Deliver → (Re)Develop.** Each stage has a small set of plays.

## 1. Discovering Value — find the job and its needs

| Play | Use it to… |
|---|---|
| Conduct Jobs Interviews | Learn the job, process, and needs from real performers (→ `interview-guides.md`) |
| Run Switch Interviews | Reverse-engineer why people changed solutions (→ `interview-guides.md`) |
| Analyze the Four Forces of Progress | Explain demand and switching behavior (→ `four-forces.md`) |
| Map the Main Job | Lay out the job as universal stages (→ `job-mapping.md`) |

## 2. Defining Value — prioritize and position

| Play | Use it to… |
|---|---|
| Find Underserved Needs | Score needs by importance × satisfaction to find opportunity (→ `needs-and-opportunities.md`) |
| Create Goal-Based Personas | Model users by the jobs and outcomes they pursue, not demographics |
| Compare Competing Solutions | Evaluate alternatives by how well they get the job done |
| Define a Jobs-Based Value Proposition | Frame the offer around the main job and top unmet needs |

## 3. Designing Value — turn insight into solutions

| Play | Use it to… |
|---|---|
| Create a Development Roadmap | Sequence work against prioritized needs / job stages |
| Align Teams to Job Stories | Express requirements as "When [situation], I want to [motivation], so I can [outcome]" |
| Architect the Solution | Map solution components to job stages and needs |
| Test Hypotheses with JTBD | Run experiments against desired outcomes (ties to Lean) |

## 4. Delivering Value — the ongoing relationship

| Play | Use it to… |
|---|---|
| Map the Consumption Journey | Model the performer's experience of *using* the solution over time |
| Onboard Customers Successfully | Reduce anxiety/habit forces at first use |
| Maximize Customer Retention | Keep serving the job as it evolves |
| Provide Relevant Support | Support the job, not just the product |

## 5. (Re)Developing Value — strategy and growth

| Play | Use it to… |
|---|---|
| Survive Disruption with JTBD | Spot when a cheaper/simpler solution is getting the job "good enough" |
| Strategize Around JTBD | Use the job as the unit of strategic decision-making |
| Organize Around Jobs | Structure teams around customer jobs rather than features |
| Expand Market Opportunities | Find adjacent and related jobs to grow into |

## Picking next steps in a report

- Thin or unvalidated data → **Conduct Jobs Interviews**, **Map the Main Job**.
- Switching behavior present → **Run Switch Interviews**, **Analyze the Four Forces**.
- Many candidate needs, unclear priority → **Find Underserved Needs** (opportunity survey).
- Insight exists, need to act → **Define a Jobs-Based Value Proposition**, **Create a Development Roadmap**, **Align Teams to Job Stories**.
